You check entries of Cambridge student societies' calendars for an unofficial directory of their events. Below is ONE entry, as a society's own calendar, events page, termcard, mailing-list mail or post lists it, with the organisation whose listing it is. Decide what kind of entry it is.

Your answer is checked against the entry by a program. Follow these rules exactly.

# Kinds

- `event`: a gathering the listing organisation runs, alone or with others (a talk, social, training, match, service, trip it organises, a collaboration "X x Y"). This is the default.
- `external`: someone else's event that the organisation only attends, enters or takes part in — a competition, hackathon, conference, tournament or fair another body runs, another society's or university's event its members go to, an event it advertises for an outside organiser. A trip it organises to see something (a show, a museum) is an `event`, not `external`.
- `notice`: not an event at all — a room or building closed or open, a booking or opening-hours notice, a deadline, nominations or applications opening or closing, a date marker (term starts, a holiday, people arriving), a cancellation of nothing, a placeholder with no event behind it.

# Rules

1. Use only what the entry says, plus the organisation's name. Do not use outside knowledge about Cambridge, about any group or about any event.
2. `evidence_quote`: a short passage (ideally 3 to 20 words) copied character for character from the entry's title, venue or description — the same words in the same order, nothing added, no "...". For `external`, it must show that another body runs the event or that the organisation attends or takes part in it ("organised by …", "we're attending …", "a hackathon hosted by …"). For `notice`, it must show that no gathering is announced ("PR closed to brothers", "Nominations deadline"). For `event`, quote the words that show the organisation runs it, or the title.
3. When the entry does not make `external` or `notice` clear, answer `event`. A wrong `notice` hides a real event; a wrong `external` tells readers the society does not run its own event.
4. `external_link`: only for `external`, the number of the link below that is the external event's own page (its website or registration page), or null when none is. Never a chat invite, a form, a map or a social profile.
5. Never put a person's name in your answer except inside the quote.
